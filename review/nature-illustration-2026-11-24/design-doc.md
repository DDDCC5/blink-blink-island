# 眨眨岛：自然插画视觉提案

2026-11-24 · 设计审阅稿 · web_design_validation_only

## 目标与范围

将现有控制面板打磨成安静的“小岛图鉴”：低矮水彩小岛是首页与结果页的识别点，训练时收起大幅装饰。已有固定左面板、中央真实训练区、右岛屿与蝴蝶的空间关系继续沿用。取消拖动的决定继续有效。本包没有修改 Android 应用、业务判定或版本，也没有安装或发布。

本轮完整视觉范围为首页、训练页和结果页。其他状态只用于检验返回、准备、暂停及记录入口的上下文；声音设置与记录管理仍须在后续原生实现中保留完整功能。本包不是可替代原生应用的业务实现。

## 为什么保持现有空间结构

二维屏幕也能完成选择、暂停与查看记录，因此这些操作集中在一个左面板。中央区域的方向与运动才是空间训练的主体，右侧岛屿承担环境陪伴作用。不给每种操作增加悬浮窗口，不移动已经确认的位置。网页只预览左面板，不能验证头显阅读距离、舒适度、真实玻璃材质与遮挡。

## 三个独立方向的取舍

|方向|操作效率与空间价值|舒适与领域表达|风险与取舍|
|---|---|---|---|
|小岛图鉴 / botanical editorial|训练入口直接呈现；中央留给训练|短文案、宽间距、低矮水彩|采用。最接近用户已确认的固定布局与完整显示要求|
|休息旅程 / chapter journey|完整流程更突出；单项另页选择|章节感强，过程连续|不采用。增加选择步骤，容易暗中改变受限闭眼项目的处理|
|自然标本 / specimen field guide|先选图示，再按开始|插画辨识突出|不采用。多一步确认，不如现有直接进入高效|

三个方向由独立上下文分别提出。提议中的评分和星级均未采用：当前真实记录不支持新的眼动分数或健康改善结论。

## 视觉与布局

系统 Vibrant 的16个公开色角色保持原名引用；森林绿、柔和薄荷色与浅纸白只作为单独品牌色。标准按钮、入口行与进度使用 vendored SpatialUI Web，布局透明，不增加装饰边框或嵌套面板填充。外层预览使用库的 Material.Regular 环境上下文；不代表已迁移原生背景。

面板默认1100×1120dp，最小960×1120dp，最大1100×1120dp。正式设备继续沿用既有窗口附件和栅格缩放修复，不能直接把这些逻辑尺寸当真实毫米。

- 首页：品牌与训练前语言切换 → 插画与欢迎短句 → 完整休息主按钮 → 两个单项入口 → 闭眼能力状态 → 记录/设置/说明。
- 训练：返回 → 模式与简短提示 → 进度 → 追踪说明 → 暂停/跳过 → 结束/返回 → 重新准备。没有语言切换。
- 结果：返回 → 插画与结束语 → 完成/未完成/跳过/中断 → 本机保存状态 → 记录与返回。

主标题48–56dp，模式标题34dp，正文与按钮32dp，辅助文字26dp。较窄尺寸只缩减插画宽度；英文欢迎标题压短，避免插画与文字争抢宽度。没有产品内滚动容器。

## 素材

`design-assets/hero-island.png` 为本轮新生成的透明水彩岛屿插画。其他蝴蝶、轨道、叶子与品牌图标沿用现有素材。插画不是训练目标，也不是可导入的3D模型；右侧真实3D岛屿不在本轮修改范围内。

## 状态与数据边界

首页可进入单项 → 3、2、1准备 → 训练；暂停/跳过/重新准备可再次进入准备；结束保存预览明确显示完成0，退出不算完成。完整休息入口保留闭眼项目受限提示，可跳过该项进入蝴蝶。这里不实现完整训练编排、自动判定或真实记录保存。

正常、空记录与保存失败样例声明在JSON中，使用URL参数 `?state=summary&case=fallback` 或 `case=error` 可复现。它们不是设备记录。训练24秒也是静态样例，不会假装自动累计、判定完成。

“摆正位置”保留原生功能入口；网页不执行空间定位。历史、设置与说明为上下文占位，不能据此替换原生统计、删除数据和音量控件。闭眼接口与佩戴提醒仍按现有能力限制处理。

## 两轮设计检查

构建前：放弃大幅铺满插画、每个区域一张卡片和新增评分；将自然插画集中在欢迎与结果，避免装饰挤占按钮。保留所有已确认的返回与退出路径。

构建后：实际浏览器检查首页、训练、结果；修短英文欢迎标题。三页中英文在默认和最小宽度共12组边界检查没有超出面板，未发现原生HTML控件替代品。10个状态最小中文尺寸也未发现面板外溢。截图为浏览器设计预览，不是Swan运行证据。

JSON Schema验证与surface-discipline检查通过。生成器的JSON快照与HTML嵌入内容一致。标准组件已通过真实点击进入准备、倒计时训练和退出记录页。尚待用户审阅视觉方向；尚待后续原生实现、悬停/手势、设备阅读与裁切验证。不能将本检查视为原生验收。

## 文件与复现

- `design-spec.json`：布局、素材、文案、状态、绑定与样例事实源。
- `preview.html`：自包含离线预览；点击蝴蝶或眼球运动入口可查看训练。
- `home.jpg`、`training.jpg`、`result.jpg`：实际浏览器截图。
- `browser-layout-checks.json`：12组中英文尺寸边界检查结果。
- `build_preview.py`、`renderer.js`：预览生成器与通用映射。

从工作区运行既有含jsonschema的Python执行 `build_preview.py` 可重建。没有新增依赖或修改机器配置。
