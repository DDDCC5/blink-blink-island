# 小岛与训练目标联动（用户已确认）

## 已确定的体验

左侧面板和右侧小岛保持固定。蝴蝶训练由岛上的蝴蝶飞入中央；眼球运动由岛上送出橙色小球。用户确认结束休息后，当前训练伙伴才自动回岛。闭眼休息保持现有语音引导。

## 方案

采用真实三维目标在岛屿与中央之间连续移动的方案。保留现有模型与SDK，不新增生成任务。与额外复制一只入场蝴蝶相比，目标接力能避免两只相同蝴蝶同时出现及交接时跳变。

## 具体流程（实现建议）

1. 选择模式并确认开始、完成必要授权后开始入场。蝴蝶沿柔和曲线飞入，小球沿轻缓弧线送出；与现有准备倒计时衔接，抵达后才开始训练计时和判定。
2. 使用实际岛屿锚点作为出发点、实际训练参考位置作为终点；保持中央目标尺寸，避免近距离扑面。入场不受目光命中判定影响。
3. 训练中沿用既有目光路径、追踪质量暂停、重试及跳过逻辑。重试不重复从岛上出发；暂停不触发回岛。
4. 自动完成训练时停住目标，显示结果，等待用户结束操作；不因完成状态立即消失或回岛。
5. 用户点击“结束休息”即确认结束，不额外增加确认弹窗。中途结束也从当前位置回岛，保持原有退出记录语义，不计作完成。返回选择同样结束当前休息并触发回岛。
6. 回岛约两秒，期间防止重复结束。完成后蝴蝶恢复岛上陪伴状态，小球收回花丛；保存记录不依赖动画结束，动画被后台切换打断也不会丢记录。
7. 完整休息中的训练类型交接与整次结束分别处理，不能误写成一次完成记录；三维目标交接过程不计分。

## 验证

覆盖首次进入、权限等待、入场结束、暂停继续、重试、自动完成等待确认、中途结束、返回选择、连续点击与后台切换。检查岛上蝴蝶无重复、入场/回岛无瞬移、计时不提前、保存幂等；最终自然度需要Swan佩戴确认。

以上时长、曲线及结果页结束入口为实现建议，尚未视为用户确认的最终细节。
