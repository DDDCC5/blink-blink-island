# 重试准备与平视三分区

用户明确要求：重试后倒计时，左侧平视训练面板，右侧常驻岛屿/蝴蝶，中间训练。沿用现有Stage和附件面板，不新增窗口、模型或SDK依赖。

实现选择：3秒准备阶段；目标回中央且冻结，不作动作判定、不累计有效时长。倒计时结束首帧清零观察时间差。暂停/切后台不偷跑准备时间；重试不额外增加成功/失败次数。保持现有校准参考与头动限制，不随重试自动放宽或改写参考。

布局：同一头部参考坐标，面板中心位于左侧约32度、水平视线高度，尺度保持0.75；岛屿整体缩小并置于右侧，视觉包围盒中心与视线同高；训练目标留在中央原有±10度/±6度范围。非训练页也使用同一左侧面板。首次有效头姿确定初始平视参考，校准取得参考后沿用它。所有实体仍由现有Kotlin场景负责。

取舍：仅倒计时无需重新完成五点，符合重试本轮的范围；重试自动重新锚定会掩盖姿态偏差，故不采用。位置数字是本轮工程选择，舒适度与可见性须真机审阅。

验证：倒计时内移动头部不失败/不计分，结束后重新判定；暂停不跳过倒计时；目标居中冻结再起步；构建及全套单测，替换安装保留数据，请佩戴者确认左右分区和重试体验。
