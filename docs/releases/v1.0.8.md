# 眨眨岛 / Blink Blink Island 1.0.8

2026-11-27 · versionCode **9** · 开发预发布版 · Spatial SDK **6.1.9**

本次公开更新包含1.0.4之后累计开发的功能与视觉改进。

## 版本说明

- **小岛与训练联动**：蝴蝶从右侧小岛飞入中央，小球从岛上沿弧线送出；用户确认结束休息后再回岛。组合训练采用旧目标回岛、新目标入场的交接，入场与交接不计入有效练习。
- **自然绘本视觉**：奶油色面板、Tripo三维岛屿和完整蓝闪蝶，头部比例修正；非对称连续扑翼、轻微翼尖变化及沿飞行方向倾转。
- **更轻松的休息选择**：快速/完整练习、开始前舒缓/标准节奏选择，短练习保留自然女声引导。
- **本地统计**：七天休息统计、最近方案与节奏保存；保留本机记录、删除记录及退出不算完成的规则。
- **空间与流程修正**：固定水平布局，使用系统长按回正；暂停、重试和返回衔接优化，退出保存与回岛动画分开，防止重复保存。

闭眼休息仍按用户选择采用语音引导，不检测眼睛开合。

## 验证与已知限制

- 16套、137项JVM测试通过；Debug/Release构建、界面样式和架构检查通过。
- 已在独立模拟器安装启动，原生首页、岛屿和蝴蝶骨骼资源加载正常。
- **完整入场、回岛动画及真实眼动尚未验收**：模拟器眼动提供器创建失败，空间自动操作和姿态注入接口不可用。Swan尚未安装1.0.8。
- 正式设计保真检查尚缺少完整实现映射；这是开发预发布版本。
