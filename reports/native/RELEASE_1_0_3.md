# 1.0.3 开发版 — 2026-11-26

Android versionName **1.0.3**，versionCode **4**。包名 `com.example.blinkblinkisland.dev`，Spatial SDK BOM 6.1.9。相较仓库上一版1.0.1，本次包含此前本地1.0.2界面更新和最新闭眼语音引导功能。

## 版本说明

- 闭眼休息改为十轮语音引导：准备倒计时后，跟随温和女声闭眼、保持3秒、睁眼、放松，再进入下一轮。不检测眼睛开合，不要求眼动或面部追踪权限。
- 恢复首页闭眼休息单项入口，完整休息包含该项。
- 暂停或切到后台会停止语音和计时；继续前倒计时3秒，并重新引导当前轮。
- 本地记录区分语音引导练习；播完流程记为完成，中途结束保留退出状态。
- 合入自然插画界面：水彩岛屿、训练进度与结果页层级、自然色彩按钮。保留固定位置、四角圆角、完整按钮与返回入口。
- 保持蝴蝶和小球训练的真实目光跟随判定，允许自然转头。
