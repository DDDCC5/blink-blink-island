# Voice script V2 / 应用双语配音稿 V2

App narration source for the approved natural female voices. Filename convention: voice_zh_<id>.wav and voice_en_<id>.wav. Never play narration simultaneously in both languages. The original handoff script is retained separately. V2 removes head-position restrictions and uses plain-language pause guidance; all other lines remain unchanged.
